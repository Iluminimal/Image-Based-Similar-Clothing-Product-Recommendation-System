# `ingestion`: датасетийг ачаалах

Kaggle-ийн "Fashion Product Images" датасетийг цэвэрлэж, жижиг зураг ба embedding үүсгэн өгөгдлийн санд
оруулна. `make ingest` ажиллуулна. Дахин ажиллуулахад хийгдсэн ажлыг давтахгүй.

| Файл | Үүрэг |
| --- | --- |
| `cli.py` | Командын сонголтууд |
| `cleaning.py` | `styles.csv`-ийг уншиж, буруу мөрийг хасах |
| `images.py` | Жижиг зураг (thumbnail), түүнийг ачаалж дуустал харуулах бүдэг зураг |
| `pipeline.py` | Бүх алхмыг холбож, санд бичих |
| `embedding_store.py` | Embedding-ийг өөр машин (Colab) дээр бодож, файлаар зөөх |
| `pricing.py` | Датасетэд үнэ, үлдэгдэл байхгүй тул тогтмол дүрмээр үүсгэх |
| `synthetic.py` | Датасетгүйгээр ажиллуулах 60 хиймэл бараа (`make seed-e2e`) |
