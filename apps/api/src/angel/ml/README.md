# `ml`: зураг таних

| Файл | Үүрэг |
| --- | --- |
| `embeddings.py` | Загварын интерфейс |
| `fashion_clip.py` | Жинхэнэ загвар (512 хэмжээст vector) |
| `fake.py` | Тест, CI-д зориулсан хиймэл загвар (юу ч татахгүй) |
| `preprocess.py` | Зургийг загварын оролт болгон бэлтгэнэ (өөр хаана ч бэлтгэхгүй) |
| `localizer.py`, `yolo.py` | Зураг дээрх хувцсыг олох |
| `classifier.py` | Хувцасны ангиллыг таамаглах |
| `gpu.py` | Хоёр загвар GPU-г зэрэг ашиглахаас сэргийлэх түгжээ |
| `metrics.py`, `evaluation.py`, `benchmark/` | Чанарын хэмжилт (дипломын ажил) |

**Анхаар:** загварын хувилбар эсвэл preprocessing өөрчлөгдвөл өмнө хадгалсан embedding-үүд шинээр гаргах
embedding-тэй таарахаа болино. Тэр үед `make ingest ARGS=--reembed` ажиллуулж, каталогийн embedding-ийг
дахин гаргана.

Дэлгэрэнгүй: [`docs/ml-pipeline.md`](../../../../../docs/ml-pipeline.md).
