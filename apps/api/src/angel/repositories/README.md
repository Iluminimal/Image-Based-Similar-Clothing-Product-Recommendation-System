# `repositories`: өгөгдлийн сантай харилцах код

SQL query бичих газар. (Service-д цөөн онцгой тохиолдол бий: advisory lock ба бүртгэл устгах үеийн
цэвэрлэгээ.)

- Commit хийхгүй: transaction-ийг service удирдана.
- HTTP, `ProblemError`-ийн талаар юу ч мэдэхгүй; олдоогүй бол `None` эсвэл хоосон жагсаалт буцаана.
- Олон мөр түгжих бол **id-ийн дарааллаар** түгжинэ, эс бөгөөс хоёр transaction бие биеэ хүлээж гацна
  (deadlock).
- `patterns.py` — хэрэглэгчийн бичсэн текстийг `LIKE`-д аюулгүй ашиглах.
