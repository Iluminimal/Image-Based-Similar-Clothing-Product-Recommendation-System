# `services`: дэлгүүрийн дүрэм

Захиалга, төлбөр, хайлт, нэвтрэлт зэргийн бүх дүрмийг энд хэрэгжүүлнэ.

- Transaction-ийг service нээж, хаана (`async with self._session.begin()`).
- Алдааг `ProblemError`-оор шиднэ (`core/errors.py`). Гарчиг, тайлбар нь хэрэглэгчид харагдаж болох тул
  [нэр томьёоны толийг](../../../../../docs/glossary-mn.md) дагаж монголоор бичнэ.
- Query-г `repositories/`-д бичиж, эндээс дуудна.
- Төлбөр зэрэг гадаад үйлчилгээний дуудлага амжилтгүй болсон ч өгөгдөл зөв үлдэх ёстой.
- Имэйлийг шууд илгээхгүй: өгөгдлөө өөрчилдөг transaction дотроо дараалалд (`system/outbox.py`)
  оруулна. Зөвхөн нэг удаагийн кодыг шууд илгээнэ.

Нийтлэг хэсэг: `mappers.py` (ORM → schema), `cache.py` (хайлтын Redis cache).
