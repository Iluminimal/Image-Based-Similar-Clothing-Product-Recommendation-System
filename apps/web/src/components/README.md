# `components`: нийтлэг UI

Хэд хэдэн боломж ашигладаг компонентууд. Нэг л боломжид хэрэгтэй бол `features/<нэр>/`-д үлдээнэ.

| Folder | Юу байдаг |
| --- | --- |
| `ui/` | Суурь элементүүд (shadcn/ui). Шинийг `npx shadcn@latest add <нэр>`-аар нэмнэ |
| `layout/` | Header, footer, цэс, хайлтын талбар |
| `product/` | Барааны карт, үнэ, од |
| `forms/` | Маягтын талбарууд |
| `admin/` | Админ дэлгэцийн хүснэгт, самбар, график |
| `motion/` | Хөдөлгөөн |
| `theme/` | Цайвар, харанхуй горим |

Шинэ компонент гараар (keyboard) ашиглагдах ёстой; хуруугаар дарах зүйлийн талбай 44px-ээс багагүй
байна.
