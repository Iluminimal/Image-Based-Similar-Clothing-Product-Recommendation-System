# `i18n`: хэл

Монгол нь анхдагч, англи нь сонголт. Бичвэрүүд `apps/web/messages/{mn,en}/`-д, боломж бүрээр
хуваагдсан файлд байна.

- Түлхүүрийг **хоёр хэлд хоёуланд** нь нэмнэ. `messages.test.ts` түлхүүр, `{орлуулах хэсэг}` зөрвөл унана.
- Монгол бичвэр [нэр томьёоны толийг](../../../../docs/glossary-mn.md) дагана. `glossary.test.ts`
  хуучирсан үг буцаж орохоос сэргийлнэ.
- Датасетээс англиар ирдэг үгс (ангилал, өнгө, улирал)-ийн орчуулга: `vocab-mn.ts`.
- Мөнгө, огноог гараар биш `format.ts` (`useFormat`)-аар харуулна. `toLocaleDateString` бүү дууд: Chrome
  монгол огнооны өгөгдөлгүй тул англиар гаргадаг. `dates.ts` монгол огноог өөрөө угсарч, бүгдийг дэлгүүрийн
  цагаар харуулна.
- API-ийн алдаа ямар бичвэрээр гарахыг `lib/api/errors.ts` шийднэ.
