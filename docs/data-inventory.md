# Хувийн өгөгдлийн жагсаалт (хуульчид өгөх техникийн тайлбар)

**Энэ бол нууцлалын бодлого биш.** Апп одоо юу цуглуулж, хаана, хэр удаан хадгалдгийг кодоос гаргаж бичсэн (2026 оны
11-р сар). Бодлого, үйлчилгээний нөхцөлийг үүн дээр тулгуурлан хуульч бичнэ. Код өөрчлөгдвөл энэ баримтыг шинэчилнэ.
Доорх хугацаанууд анхдагч тохиргоо бөгөөд өөрчилж болно.

## 1. Сервер дээр хадгалдаг (PostgreSQL)

| Өгөгдөл | Юу агуулдаг | Хэр удаан | Хэрэглэгч бүртгэлээ устгахад |
| --- | --- | --- | --- |
| Бүртгэл | имэйл, утас, нэр, нууц үгийн хэш (argon2id), Google-ийн профайл зургийн хаяг, баталгаажсан огноо | бүртгэл байх хугацаанд | имэйл, утас, нэр, нууц үг, зураг арилна. Мөр нь нэргүй болж үлдэнэ (захиалга түүнийг заадаг) |
| Google холболт | Google-ийн таних дугаар, имэйл | бүртгэл байх хугацаанд | устна |
| Хүргэлтийн хаяг | нэр, утас, аймаг/хот, дүүрэг, хороо, хаяг, шуудангийн код, улс | хэрэглэгч устгах хүртэл | устна |
| Сагс, хадгалсан бараа | бараа, хэмжээ, тоо | зочны сагс: сүүлд өөрчилснөөс 30 хоног | устна |
| **Захиалга** | бараа, дүн, холбоо барих имэйл, **тухайн үеийн хүргэлтийн хаяг (нэр, утас, хаяг)**, төлөв, тээвэрлэгч, хяналтын дугаар | **хугацаагүй** | **үлдэнэ** (санхүүгийн бичлэг) |
| Захиалгын түүх | төлвийн өөрчлөлт, ажилтны тэмдэглэл, шалтгаан | хугацаагүй | үлдэнэ |
| Цуцлах, буцаах хүсэлт | шалтгааны ангилал, хэрэглэгчийн бичсэн тайлбар, шийдвэрийн тэмдэглэл | хугацаагүй | хэрэглэгчийн тайлбар арилна, бусад нь үлдэнэ |
| Төлбөр | төлбөрийн үйлчилгээ, түүний нэхэмжлэх ба гүйлгээний дугаар, дүн, төлөв. QR-ын мэдээлэл төлбөр дуусмагц арилна | хугацаагүй | үлдэнэ |
| Сэтгэгдэл | үнэлгээ, гарчиг, бичвэр. Нийтэд зохиогчийг «Нэр О.» маягаар харуулна | хугацаагүй | үлдэнэ, зохиогч нь нэргүй болно |
| Нэвтэрсэн төхөөрөмж | токены хэш, **IP хаяг**, browser-ийн мэдээлэл (user agent), цаг. Хэрэглэгч өөрийнхөө төхөөрөмж, IP-г харна | дууссанаас хойш 30 хоног (идэвхтэй нэвтрэлтийн эхний бичлэг үлдэнэ) | устна |
| Аюулгүй байдлын үйл явдал | нэвтрэлт, нууц үг солих гэх мэт; арга, **IP**, user agent | 180 хоног | устна |
| Нэг удаагийн код | утас эсвэл имэйл, кодын хэш | 24 цаг | устна |
| Илгээх имэйлийн дараалал | хүлээн авагч, гарчиг, бичвэр (захиалгын имэйлд хаяг, утас орно) | илгээмэгц бичвэр арилна; мөр нь 7 хоног, илгээж чадаагүй бол 30 хоног | дууссан мөр устна; хүлээгдэж буй нь илгээгдсэний дараа цэвэрлэгдэнэ |
| Ажилтны үйлдлийн бүртгэл | ажилтны имэйл эсвэл утас, үйлдэл, захиалга/барааны дугаар, ажилтны бичсэн шалтгаан | хугацаагүй | үлдэнэ (ажилтны бүртгэлийг сайтаас өөрөө устгах боломжгүй) |
| Ажилтны хоёр шатлалт нэвтрэлт | нууц түлхүүр (шифрлэсэн, AES-GCM), нөөц кодын хэш | бүртгэл байх хугацаанд | хамаарахгүй |

Нөхцөл: нээлттэй (дуусаагүй) захиалгатай хэрэглэгч бүртгэлээ устгаж чадахгүй.

## 2. Хадгалдаггүй

* **Зургаар хайхад оруулсан зураг, камерын шууд дүрс:** санах ойд боловсруулаад диск болон өгөгдлийн санд бичдэггүй
  (тест: `apps/api/tests/catalog/test_search_privacy_api.py`). Зургийг хадгалахыг зөвшөөрөх сонголт ч байхгүй.
* **Картын болон банкны дансны мэдээлэл:** апп асуудаггүй, хадгалдаггүй.
* **Хайсан үг:** өгөгдлийн сан болон API log-д бичдэггүй. Үгээр зургийн төрлийн хайлт хийхэд гарсан тооцооллын үр
  дүнг (embedding) Redis-д 24 цаг түр хадгалдаг; түлхүүр нь бичвэрийн хэш.

## 3. Redis (түр санах ой)

Түр cache (каталог, төстэй бараа, дээрх embedding) ба хүсэлтийн давтамжийг хязгаарлах тоолуур. Тоолуурын түлхүүрт
**IP хаяг**, амжилтгүй нэвтрэлтэд имэйл эсвэл утасны хэш орно. Бүгд хугацаа дуусаад өөрөө устна. Redis-ийг backup-д
авдаггүй.

## 4. Хэрэглэгчийн browser дээр

| Нэр | Зорилго |
| --- | --- |
| cookie `lk_refresh` | нэвтрэлтийг үргэлжлүүлэх (JavaScript уншиж чадахгүй; 30 хоног) |
| cookie `lk_session` | нэвтэрсэн эсэхийн тэмдэг |
| cookie `lk_cart` | зочны сагс (30 хоног) |
| cookie `lk_oauth` | Google-ээр нэвтрэх явцын түр тэмдэг |
| cookie `NEXT_LOCALE` | сонгосон хэл |
| localStorage | сүүлийн 5 хайлт, сүүлд үзсэн 12 бараа, харагдацын тохиргоо (өдөр/шөнө, камерын горим; ажилтны цэсний байдал). Серверт илгээдэггүй |
| sessionStorage | нэвтрэхээс өмнө «Хадгалах» дарсан бараа (таб хаахад арилна) |

Web-ийн кодонд гуравдагч этгээдийн analytics, зар, мөрдөх script **байхгүй**.

## 5. Гадны үйлчилгээ рүү очдог

| Үйлчилгээ | Юу илгээнэ | Юу хүлээн авна |
| --- | --- | --- |
| QPay (төлбөр) | захиалгын дугаар, дүн, «Angel <дугаар>» тайлбар, буцаж мэдэгдэх хаяг, дэлгүүрийн нэхэмжлэхийн кодууд. **Хэрэглэгчийн нэр, имэйл, утас илгээхгүй** | нэхэмжлэх, QR, төлбөрийн төлөв ба дүн |
| Twilio (SMS) | хэрэглэгчийн утасны дугаар, кодтой мессеж | илгээлтийн хариу |
| SMTP үйлчилгээ (имэйл) | хүлээн авагчийн имэйл, гарчиг, бичвэр (захиалгын имэйлд бараа, дүн, хаяг, утас) | илгээлтийн хариу |
| Google (нэвтрэх) | Google-ийн стандарт нэвтрэлтийн хүсэлт (`openid email profile`) | таних дугаар, имэйл, нэр, профайл зургийн хаяг |
| Hugging Face (загвар татах) | сервер асахад загварын файл татна; **хэрэглэгчийн өгөгдөл илгээхгүй** | загварын файл |

Зураг таних сангийн (`ultralytics`) статистик илгээлт унтраалттай. Сервер, backup, дээрх үйлчилгээнүүд **аль улсад
байрлахыг** та сонгосон үйлчилгээ үзүүлэгчээс хамаарна.

## 6. Log

Production-ийн API log: хүсэлтийн арга, зам (`?`-ийн дараах хэсэггүй), төлөв, хугацаа, дугаар. Хүсэлтийн log-д IP
бичдэггүй. Амжилтгүй нэвтрэлтэд имэйлийн хэшийн хэсэг, SMS-д хагас далдалсан дугаар, имэйлд зөвхөн гарчиг бичнэ.
Caddy-ийн хандалтын log асаагаагүй. Хөгжүүлэлтийн `console` горим SMS, имэйлийг бүтнээр нь log-д бичдэг бөгөөд
production-д хориотой. Log-ыг хэр удаан хадгалах нь серверийн тохиргооноос хамаарна.

## 7. Backup

Backup нь өгөгдлийн сан бүхэлдээ болон барааны зураг. Устгасан өгөгдөл хуучин backup эргэлтээс гарах хүртэл тэнд
үлдэнэ (анхдагчаар сүүлийн 14 хувь; өдөрт нэг бол 2 долоо хоног). Серверээс гадна хуулсан backup-ын хугацааг та
тогтооно.

## 8. Хуульчаар шийдүүлэх асуултууд

1. Захиалгын бичлэгийг (нэр, утас, хаягтай) **хэдэн жил хадгалах ёстой** вэ? Хугацаа өнгөрсний дараа нэргүй болгох уу?
   Одоо хугацаагүй.
2. Захиалгын түүх, ажилтны үйлдлийн бүртгэл, сэтгэгдлийн бичвэрийг хэр удаан хадгалах вэ? Одоо хугацаагүй.
3. Дээрх хугацаанууд (24 цаг, 7, 30, 180 хоног) шаардлагад нийцэх үү?
4. Буцаах хугацаа (анхдагч 14 хоног) ба буцаалтын хүргэлтийн зардлыг хэн төлөх вэ?
5. Cookie ба localStorage-д зөвшөөрөл асуух шаардлагатай юу?
6. Өгөгдөл гадаад дахь үйлчилгээ рүү (Twilio, Google, SMTP, сервер) очиход нэмэлт зөвшөөрөл, мэдэгдэл хэрэгтэй юу?
7. Нууцлалын бодлого, үйлчилгээний нөхцөлийн эх бичвэр. Сайтад эдгээр хуудас одоогоор **алга**.
